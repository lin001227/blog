## 一、这是什么东西？

**一句话：你儿子自己写的一个个人网站，用来发布文章、管理内容、和读者互动。**

就像你平时刷的公众号或者新闻网站，但这个是属于他自己的——想写什么写什么，想怎么排版就怎么排版，没有任何广告和限制。

### 它的名字

**风屿 · 随笔** — "风屿"象征自由飘荡的思想岛屿，"随笔"就是随手写的文章。

### 它能帮你儿子做什么？

| 你能做的事 | 简单说就是 |
|-----------|-----------|
| 📝 **写文章** | 像写 Word 文档一样，支持标题、加粗、代码块、图片 |
| 🏷️ **分类整理** | 给文章贴上"技术"、"生活"、"读书"之类的标签 |
| 📌 **置顶重要文章** | 让最重要的文章始终排在最前面 |
| 💬 **管理评论** | 读者留言了可以审核、回复、删除 |
| 🔍 **全文搜索** | 输入关键词就能找到相关文章 |
| 🤖 **大模型排行榜** | 展示当前热门 AI 模型的排名（可以自己编辑） |
| 📡 **RSS 订阅** | 读者可以用阅读器订阅，有新文章自动推送 |
| 📧 **邮件订阅** | 读者留邮箱，有新文章时自动发邮件通知 |
| 🎨 **深色模式** | 夜晚看博客不刺眼，一键切换 |
| 📱 **手机也能看** | 在手机上排版自动适配，很好用 |

## 四、技术架构（简单版）

```
                    ┌─────────────┐
                    │  你的浏览器   │  ← 你在电脑/手机上访问
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │  Nginx 服务器 │  ← 负责接收请求、分发
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
     ┌────────▼───┐ ┌─────▼─────┐ ┌───▼────────┐
     │  Vue 前端   │ │ Spring    │ │  MariaDB   │
     │ (界面展示)  │ │ Boot 后端  │ │  数据库    │
     │  / 网页    │ │ (业务逻辑) │ │ (存数据)   │
     └────────────┘ └───────────┘ └────────────┘
```

**打个比方：**
- **Nginx** = 前台接待员，告诉你该去哪
- **前端** = 商店橱窗，展示所有内容给你看
- **后端** = 仓库管理员，处理订单、整理货物
- **数据库** = 仓库货架，所有东西都存这里

## 五、部署方式

**Docker 一键部署** — 就像用集装箱装货一样，把整个博客打包成一个标准单元。

只需要在服务器上执行：
```bash
docker compose up -d
```

三个服务就全部启动了：
1. **blog-db** — 数据库（存文章、评论、用户等信息）
2. **blog-backend** — 后端程序（处理登录、文章增删改查）
3. **blog-frontend** — 前端网页（展示给访客看）
